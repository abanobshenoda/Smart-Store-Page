# Stitch AI Design Prompts - User Account Pages

## Prompt: Account Dashboard

```
Design a user account dashboard for "Smart Store" - Egyptian shoe e-commerce.
RTL Arabic layout.

Layout: Two columns. Right sidebar (25%) with user menu, left main content (75%).

SIDEBAR MENU:
- Profile photo + name "أحمد محمد"
- Items: لوحة التحكم, طلباتي, المفضلة, عناويني, طرق الدفع, نقاط الولاء, اعدادات الحساب, تسجيل خروج

MAIN CONTENT:
- Welcome message: "مرحباً أحمد"
- 4 stat cards: 12 طلب, 5 مفضلة, 2500 نقطة, 4.8 تقييم
- Latest orders list with status badges
- Recently viewed products section

Style: Clean cards, white background, blue accents
```

## Prompt: Order History Page

```
Design an order history page for user account. RTL Arabic.

- Filter tabs: الكل, قيد المعالجة, قيد الشحن, تم التوصيل, مرتجع
- Order cards with: order number, date, status badge, product images, total, action buttons (تتبع, إعادة الطلب, تكتب تقييم)
- Pagination at bottom
```

## Prompt: Order Tracking Page

```
Design an order tracking page. RTL Arabic.

- Status timeline with vertical stepper: تأكيد الطلب, جاري التجهيز, تم الشحن, قيد التوصيل, تم التوصيل
- Each step shows date/time, completed steps have green checkmark
- Order details: products with images, sizes, colors, quantities, prices
- Delivery address card
- Shipping company info and tracking number
```

## Prompt: Wishlist Page

```
Design a wishlist page. RTL Arabic.

- Title: "المفضلة (5 منتجات)"
- Product grid with cards: delete button (top), 3D shoe image, product name, price, "أضف للسلة" button
- "مسح الكل" button at bottom
- Empty state: heart icon + "المفضلة فارغة" + CTA
```

## Prompt: Address Book Page

```
Design an address book page. RTL Arabic.

- "+ إضافة عنوان" button at top
- Address cards: type icon (home/work), name, phone, full address, default badge, edit/delete buttons
- Add/Edit modal with form fields
```
