# Stitch AI Design Prompts - Home Page

## Prompt 1: Hero Section

```
Design a stunning hero section for an Egyptian shoe store e-commerce website called "Smart Store".

Style: Modern, elegant, luxurious
Direction: RTL (Arabic)
Color Scheme: Primary Blue (#0ea5e9), White, Dark Gray (#171717), Gold accents (#d4af37)

Requirements:
1. Full-width hero section with gradient background (blue to purple)
2. Large 3D shoe model floating in center-right with shadow
3. Arabic text on left side:
   - Main heading: "ادخل عالم الأناقة" (Step Into Style)
   - Subheading: "أحذية مميزة للمصريين" (Premium Egyptian Footwear)
   - CTA Button: "تسوق الآن" (Shop Now) with gold glow effect
4. Animated particles floating in background
5. Scroll indicator at bottom
6. Navigation bar at top with:
   - Logo "Smart Store" with shoe icon
   - Links: المنتجات, التصنيفات, العروض
   - Icons: Search, Account, Cart with badge
   - Language toggle: AR | EN
7. Mobile responsive design
8. 3D depth effect with shadows
```

## Full Home Page Prompt

```
Design a complete home page for "Smart Store" - a premium Egyptian shoe e-commerce website.

IMPORTANT: This is an RTL (Right-to-Left) Arabic website.

Design System:
- Primary Color: Sky Blue (#0ea5e9)
- Secondary: Purple (#d946ef)
- Accent: Gold (#d4af37)
- Background: White
- Text: Dark Gray (#171717)
- Font: Arabic font (Cairo or Tajawal)

Page Sections (top to bottom):

1. NAVBAR:
   - Sticky navigation
   - Logo: "Smart Store" with shoe icon
   - Nav links: المنتجات | التصنيفات | العروض | المتاجر
   - Icons: Search | Account | Cart(3) | AR/EN toggle
   - White background with subtle shadow on scroll

2. HERO SECTION:
   - Full-width gradient background (blue → purple)
   - Large 3D floating shoe model (right side)
   - Arabic heading: "ادخل عالم الأناقة"
   - Subheading: "أحذية مميزة للمصريين"
   - CTA: "تسوق الآن" (Gold button)
   - Animated particles
   - Scroll indicator

3. FEATURED PRODUCTS:
   - Section title: "منتجات مميزة" with gold underline
   - 4-5 product cards in carousel
   - Cards: 3D shoe image, Arabic name, EGP price, ratings, colors, Add to Cart
   - Hover: lift + shadow

4. CATEGORIES:
   - Section title: "تصفح التصنيفات"
   - 6 category cards in grid
   - Each: background image, category name, product count
   - Hover: zoom effect

5. FLASH SALE BANNER:
   - Full-width red/orange gradient
   - "عرض خاص - خصم يصل إلى 50%"
   - Countdown timer
   - CTA: "تسوق العروض"

6. BRANDS:
   - Section title: "العلامات التجارية"
   - Horizontal row of brand logos (Nike, Adidas, Puma, etc.)
   - Grayscale → Color on hover

7. NEWSLETTER:
   - Dark background
   - "اشترك في نشرتنا البريدية"
   - Email input + Subscribe button
   - Social media icons

8. FOOTER:
   - Dark gray background
   - 4 columns: About, Links, Customer Service, Contact
   - Payment icons
   - Copyright

Design Style:
- Modern, clean, elegant
- 3D depth effects
- Smooth animations
- Card-based layout
- Mobile-first responsive
- Egyptian market focus
```
