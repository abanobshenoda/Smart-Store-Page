# Stitch AI Design Prompts - Master Index

## How to Use

1. Open [Stitch AI](https://stitch.withgoogle.com/)
2. Copy the prompt from the relevant file
3. Paste into Stitch AI
4. Generate the design
5. Export the design as code or screenshots
