## Dashboard Layouts

### Layout 1: Classic Sidebar
```
Prompt: "Design a classic dashboard layout:
- Left sidebar with navigation
- Top header with user info
- Main content area
- Sidebar: Dark gray background
- Header: White with shadow
- Content: Light gray background
- Responsive: Sidebar collapses on mobile"
```

### Layout 2: Modern Minimal
```
Prompt: "Create a modern minimal dashboard:
- Top navigation bar
- Clean white background
- Card-based layout
- Minimal shadows
- Lots of whitespace
- Elegant typography"
```

### Layout 3: Data-Heavy
```
Prompt: "Design a data-heavy dashboard:
- Multiple chart sections
- Dense information layout
- Compact cards
- Efficient use of space
- Quick scanning support"
```

```
Prompt: "Create animated stats cards:
- Card with icon, value, label
- Trend indicator (up/down arrow)
- Percentage change
- Hover: Lift + shadow
- Animation: Count-up on load
- Colors: Brand colors for each stat"
```
